☁ SmartPlayer 클라우드 동기화

기존 재생 기능은 그대로 사용합니다. 동기화는 선택 사항입니다. 연결 정보는 이미 입력되어 있습니다. 이메일과 비밀번호로 개인 계정을 생성하거나 로그인하세요. 비밀키(service_role / secret)는 절대 입력하지 마세요.

계정으로 로그인하면 내 음악 목록을 PC와 모바일에서 동기화할 수 있습니다.

음악 등록·수정·삭제 시 자동 동기화하고, 화면을 다시 열거나 일정 시간이 지나면 다른 기기의 변경 사항을 가져옵니다. 충돌 시 수정 시간이 최신인 데이터를 우선하며, 실수에 대비해 JSON 백업을 보관하세요.
